03 — Practice

What I get hired for

Two lanes, one method: manual-first testing chained to real business impact, delivered in language engineering and auditors can both act on.

OFFENSIVE

Application & API penetration testing

Black-box and grey-box assessments of web apps, REST and GraphQL APIs, and mobile back ends — hunting logic flaws a scanner will never reach.

  • OWASP Top 10 plus business-logic abuse

  • Reproducible proof-of-concept for every finding
AI

AI application security testing

Adversarial testing of LLM-backed features — and the ordinary application bugs sitting underneath the model, which is usually where the real damage is.

  • Direct & indirect prompt injection
  • Agent and tool-call abuse, excessive agency
  • RAG retrieval and training-data leakage
